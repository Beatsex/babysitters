# specialization-shared

`shared/` is the home for cross-domain library assets — skills, and eventually agents and processes, that are useful across many specializations rather than belonging to any single domain. Per the library placement policy, only assets with genuine cross-domain applicability live here.

This skill is the entry point for the `shared` specialization in the babysitter process library. Full process/skill/agent inventory, descriptions, and exact invocation commands live in the canonical file:

`library/specializations/shared/SKILL.md`

Read that file before acting - it lists every available process (with the `babysitter run:create` command to run it), and any sub-skills or sub-agents defined under this category. Do not duplicate or re-derive that inventory here; treat it as the source of truth and this file only as the trigger/pointer.
